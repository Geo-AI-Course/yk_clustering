# yk_clustering
קלאסטרינג (לא מפוקח) של יעודי קרקע כך שיתקבל סיווג שכונות/אזורים סטטיסטיים למקבצים אופייניים. אפליקציה אפשרית: הזנת יעודי קרקע של תכנית חדשה כקלט (אולי לא רק מתל אביב?), וקבלת פלט של המקבץ אליו היא משתייכת. לדוגמה: אדריכל מזין את הקבצים של תכנית שהוא מציע, ומגלה שהיא מזכירה במאפייניה את אזור כיכר המדינה בתל אביב. האם לזה הוא מכוון?
