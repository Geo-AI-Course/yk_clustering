# yk_clustering
### קלאסטרינג (לא מפוקח) של יעודי קרקע (בתל אביב בלבד?) כך שיתקבל סיווג שכונות/אזורים סטטיסטיים למקבצים אופייניים
- קישור לדאטה-סט (מצורף גם כ-CSV): https://gisn.tel-aviv.gov.il/arcgis/rest/services/WM/IView2WM/MapServer/514 
- אפליקציה אפשרית: הזנת יעודי קרקע של תכנית חדשה כקלט (אולי לא רק מתל אביב?), וקבלת פלט של המקבץ אליו היא משתייכת.
- לדוגמה: אדריכל מזין את הקבצים של תכנית שהוא מציע, ומגלה שהיא מזכירה במאפייניה את אזור כיכר המדינה בתל אביב. האם לזה הוא מכוון?
- מקורות נתונים: אם מדובר רק בתחום תל אביב, אז שכבת יעודי קרקע עירונית. אם מרשויות נוספות אז אולי מהמבא"ת
- אתגרים:
  - פורמט:
    - שכבת יעודי קרקע תל אביב כוללת פורמטים שונים, כאשר תכניות חדשות תואמות למבא"ת אך אולי אף מותאמות לפורמט של תל אביב
    - תכניות חדשות יוגשו בפורמט של מבא"ת
    - לכן בכל מקרה נרצה להמיר את הפורמט של תל אביב ואת פורמט מבא"ת לפורמט אחיד משותף
  - לפי אילו פרמטרים מקבצים? איך ממדלים?
    - אחוז של כל יעוד?
    - ניתוח מרחבי כלשהו של פריסת היעודים? למשל צפיפות צמתים ומאפייני רשת הרחובות המוצעת
    - מרחקים בין יעודים שונים, מידת עירוב השימושים
  - איזה עיבוד מקדים צריך לעשות לפני שמאמנים? שיוך לשכונה/אזור סטטיסטי, סיכום לפי האזור הסטטיסטי ואז מסווגים את האזורים?
  - איזה מודל? איך מאמנים?
